# 🚀 HHGoa Builder Studio 2026

> **Every Expedition Begins With An Identity.**

HHGoa Builder Studio is a modern web application built for **Hacker House Goa 2026 – Task 1**. It allows builders to create beautiful, editorial-style Builder Passes and Team Expedition Passes through an interactive, real-time experience.
**Here is the link** : https://hh-goabuilderstudio.vercel.app/

---

## 🌟 Live Experience

Instead of a simple form, Builder Studio guides users through a complete journey:

- 🏕️ Choose Solo or Team Expedition
- 📸 Upload & edit portrait
- 📝 Fill builder details
- 🎨 Watch the Builder Pass update in real time
- 📥 Export high-resolution social-ready assets

Designed to feel like an official expedition credential rather than just another ID card generator.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/samu22112005/task1-HackerHouse-.git
```

Go inside the project

```bash
cd task1-HackerHouse-
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Visit

```
http://localhost:3000
```
